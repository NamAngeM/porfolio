Automatisation du TCO

Bêta

Pipeline d'automatisation Python (OpenPyXL) pour la consolidation des offres fournisseurs. Temps de traitement réduit de 3 jours à 5 minutes (gain x864) avec une fiabilité renforcée.

Le problèmeLe service administratif consacrait jusqu'à 3 jours à comparer manuellement les DPGF (Excel hétérogènes) reçus de chaque entreprise candidate, avec un fort risque d'erreur sur les codes BPU.

Ma missionConcevoir une application Streamlit + un parser Python (OpenPyXL, Pandas, regex) qui ingère les DPGF, détecte les codes par fuzzy-matching, fusionne dans le TCO modèle et exporte un Excel prêt à l'arbitrage — déployée sur Render.

Pipeline applicatif

Upload DPGF → Parser regex → Merger TCO → Alertes → Export Excel

Fiabilisation du prévisionnel de facturation

Fiabilité 90%

Pipeline Make + Python (Pandas) pour détecter les écarts de facturation et alimenter des dashboards de suivi. Fiabilité du prévisionnel portée à 90%, contre des écarts non détectés en amont auparavant.

Le problèmeDes heures saisies sans articles facturables, des écarts entre les heures Wandeed et les exports Lucca détectés trop tard, un prévisionnel chronique sous-fiabilisé.

Ma missionSurveiller automatiquement les dépôts SharePoint, parser les CSV Lucca / Wandeed, croiser avec la base Notion projets et créer une ligne d'écart pour chaque anomalie — Pandas pour l'analyse en aval.

SharePoint Watch → Download CSV → Parse CSV → Aggregator → Notion Search → API Call → Create Item

Suivi automatisé des heures & escalade 3 niveaux

En production

Système d'alertes automatisées qui notifie les collaborateurs n'ayant pas renseigné leurs heures de travail dans l'ERP Wandeed, avec escalade hiérarchique progressive en 3 niveaux : collaborateur → manager → N+2. Vérification de persistance avant chaque relance, relances jamais redondantes.

Le problèmeChaque semaine, plusieurs collaborateurs oublient de saisir leurs heures dans l'ERP Wandeed. Conséquence : prévisionnel de facturation faussé, relances manuelles chronophages pour les managers et tensions hiérarchiques sur les rappels.

Ma missionConcevoir un scénario Make qui croise les saisies Wandeed avec la base Notion projets, identifie les collaborateurs en défaut de saisie et déclenche automatiquement une cascade d'alertes e-mail : J+1 au collaborateur, J+4 au manager si non régularisé, J+6 au N+2 en dernier recours — avec log Notion centralisé pour traçabilité.

Scénario Make — escalade 3 niveaux

Notion Search saisies → Router 4 conditions → Aggregator → Log alerte → Email collab. (vendredi) → Email manager (lundi) → Email N+2 (mercredi)
Make Notion SharePoint Wandeed Lucca
